## Website and PDF, one manuscript

The production download is the **full semantically tagged PDF**, with selectable syntax-coloured code, contents, bookmarks and structured links. It replaces the earlier untagged reading export at the standard download URL. Its exact-artifact PDF/UA-1 machine-validation result is recorded with this release. Machine validation is not independent semantic reading-order, WCAG or actual assistive-technology approval.

Chapters, reading guidance, publication details and captured reference data are maintained in `content/`. The website and PDF are built from that source. Local fonts and their notices are bundled. No external font service, analytics or reader account is required.

The API register preserves captured declarations and source-definition routes. It is not a complete explanation of every HTML algorithm, inherited contract, exception or conversion. The formal scope ledger and specialist review records remain in [the audit archive](docs/final-audit/README.md). Publication acceptance does not silently close those requirements or grant an accessibility/security certificate.

## Source and deployment

GitHub stores the source. **Vercel remains the website host**, not GitHub Pages. A push alone does not establish that production has deployed; see the separately dated delivery/deployment receipt for observed results.

The ZIP release includes the precompiled `site/`, canonical inputs, local fonts, PDF, builders, notices, verification evidence and `vercel.json`. Node **24.x** is required for the deployment build. See [the production notes](PRODUCTION-READINESS.md) for the repeatable build and [SEO operations](SEO-OPERATIONS.md) for environment-specific discovery settings. No new hosting service or account migration is required.

Contributors should pull with `git pull --ff-only origin main` and preserve their own edits. Credentials do not belong in the repository or release archives.
