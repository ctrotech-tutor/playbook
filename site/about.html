About the book

Learn the document.
Then learn the edge cases.

For people who want to explain their markup, not just copy a page that happens to render.

How to read it

Follow the chapters for the curriculum. Each has objectives, an example, a mistake to consider and an exercise with an explained answer. Use the reading guide to choose a route and a practice routine. Open the projects when you want a complete static folder to inspect.

The writing standard

The book uses plain language without treating browser behavior as simpler than it is. Standards requirements, authoring advice and implementation limits have different roles. Examples have a purpose and source links for further checking. Preparation was AI-assisted; the publication credits record the author and preparation details.

What this edition is

This is a published reading curriculum with captured reference inventories. It is not a completed whole-Standard behavioral reference. Independent technical, answer-key, accessibility and security reviews remain open. The PDF has selectable text, links and bookmarks, but is not a tagged accessible PDF.

The reference preserves captured element and attribute summaries, declaration signatures and source routes. A signature is not an explanation of every algorithm, exception or inherited member. The scope and checks page separates executed checks from the reviews still open.

Website and PDF

Website and PDF share the maintained chapter source. Use the exact code download for copying: some files are fragments and some media or server resources are illustrative. The seven project downloads are complete static teaching folders, not live services. Reading progress stays in this browser when storage is available; it is not an assessment or certificate.

Syntax colouring helps distinguish parts of the source; it does not prove correctness. Wrapped examples are browser demonstrations, not application backends. External media examples require their own actual resources.

Publication and corrections

The maintained source is versioned in the author’s GitHub repository. The public reading site is ctrobook.vercel.app, served through Vercel. The author confirmed successful delivery on 14 October 2026; later editions still need their own deployment.

Read the edition notes or report a correction. Public feedback must not contain private data or credentials.
