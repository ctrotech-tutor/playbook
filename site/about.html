About the book

Learn the document.
Then learn the edge cases.

For people who want to explain their markup, not just copy a page that happens to render.

How to read it

Follow the chapters for the curriculum. Use the reference to find a feature and its source. Open the projects when you want a complete folder to inspect. Each chapter has an example, a mistake to consider and an exercise with an explained answer.

The writing standard

The book uses plain language without treating browser behavior as simpler than it is. Standards requirements, authoring advice and implementation limits need to be distinguished. Examples have a purpose and source links for further checking. Preparation was AI-assisted; the publication credits and review status explain what that means for this edition.

What this edition is

A complete set of chapter drafts, not a completed audit of every algorithm and API member in the HTML Standard. The review-status page lists evidence and remaining work. Check that page before treating an example or answer as independently approved.

Website and PDF

Both are built from the same chapter data. Download all 74 exact code files. Some are fragments, intended for a complete UTF-8 document. Wrapped examples are separate browser demonstrations. The PDF is a review copy; it is not represented as an accessibility-certified export. External media examples require their own real resources. The local sandbox deliberately blocks network requests and form submissions.

Deployment

The maintained source is versioned in the author’s GitHub repository. Vercel serves the compiled static site; no GitHub Pages workflow is used. Deploy with the Vercel CLI or connect the repository to the existing Vercel project. Automated checks and local previews do not establish that a hosted deployment succeeded.
