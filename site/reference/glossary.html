A shared vocabulary

Glossary

Accessible name

The text alternative used to identify an interface element in accessibility APIs, computed from the relevant naming rules and relationships.

Attribute

A name and value associated with an element. Its authoring syntax and behavior depend on its definition and context.

Boolean attribute

An attribute whose defined true state is represented by presence and false state by absence. The string false does not turn it off.

Browsing context

A context in which a document can be presented, such as a top-level page or an embedded iframe, with further terminology defined by the Standard.

Character reference

HTML source syntax that represents a character, such as &lt; for a less-than sign in a relevant parsing context.

Conformance

Satisfaction of the applicable requirements of a specification. A checker result has a version and scope; it is not a general accessibility or security certificate.

Content model

The defined rules for an element's contents, including categories and additional restrictions.

Content category

A classification used by the Standard to describe elements and content rules. Categories can overlap or have conditional membership.

Content attribute

An attribute represented in the markup/DOM attribute layer, distinguished from a corresponding IDL property and current control state.

Custom element

An element defined through the custom-elements machinery. A valid autonomous custom-element name has a required hyphen and other naming restrictions.

Descendant

A node reached by following child relationships one or more levels down the tree. It need not be a direct child.

Document element

The element child of a document; for an ordinary HTML document it is html.

DOM

The document object model: nodes, relationships and APIs through which software can inspect and modify documents.

Enumerated attribute

An attribute defined in terms of keywords and states, potentially with distinct missing-value and invalid-value defaults.

Fallback

An alternative path or representation designed for the actual failure or unsupported case. Its presence does not prove that users can reach or use it.

Flow content

A content category covering much of the material used in a document body. Membership still depends on the individual element definition.

Focus

The platform's designation of an interaction target for relevant input. Focusable and sequentially focusable are related but distinct concepts.

Fragment

The part of a URL introduced by #, commonly used to navigate to a matching id within a document.

Global attribute

An attribute applicable across HTML elements under its defined rules. This does not remove contextual constraints or cross-specification ownership.

Hyperlink

A link to another resource or location, commonly created by an a element with href.

IDL property

A property exposed through a web interface. Reflection can parse or normalize an attribute, and some properties represent live state rather than raw markup.

Inert

A state that suppresses certain interaction and focus behavior and affects accessibility exposure under the relevant platform rules.

Landmark

An accessibility role identifying a useful region for navigation, such as main content or a named navigation area.

Living Standard

A specification maintained over time rather than a single frozen feature release. Its current presence and browser support are separate questions.

Metadata

Information about the document or its relationships, commonly placed in head using elements such as title, meta and link.

Namespace

A mechanism distinguishing vocabularies and names, important at HTML, SVG, MathML and XML integration boundaries.

Origin

A security-relevant identity derived under platform rules, ordinarily involving scheme, host and port for a conventional URL. Opaque origins and special cases exist.

Phrasing content

A category used for text and markup that participates at the phrasing level of a document. Extra element-specific restrictions still apply.

Progressive enhancement

Designing an appropriate useful baseline and adding capabilities without needlessly destroying that baseline when an enhancement fails.

Reflection

The defined relationship between a content attribute and an interface property. It is not a universal raw-string equivalence.

Sandbox

A set of restrictions for an embedded browsing context. Added permission tokens restore capabilities and must be reviewed for the actual trust boundary.

Serialization

A textual representation of a document or fragment. HTML and XML serialization have different rules and processing consequences.

Shadow tree

A DOM tree attached through a shadow root, used for encapsulation and composition. It is not a general security sandbox.

Slot

A placeholder for assigned content in a shadow tree. A slot element and a slot attribute have different jobs.

Text alternative

A textual replacement or representation suited to non-text content's actual purpose and context.

Tokenization

The parsing stage that recognizes tokens according to the tokenizer's state before tree-construction rules process them.

Transparent content model

A model that derives permitted content from the surrounding context while preserving the element's own additional restrictions.

Tree construction

The parsing rules that turn tokens into nodes and relationships, including specified recovery behavior.

Void element

An HTML element that has no contents and no end tag in HTML syntax, such as img or input.

WebVTT

A text format commonly used for timed text tracks. A valid file still needs content review against the actual media.
