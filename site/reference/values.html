Value syntax is part of the language

Values and microsyntaxes

A starting map to the definitions. This is not yet a complete value, keyword and default registry.

  • Boolean attributes: Presence and absence, plus permitted serialized values.
  • Keywords and enumerated attributes: Keywords, states and missing/invalid-value defaults.
  • Numbers: Do not substitute JavaScript numeric parsing for an attribute's defined syntax.
  • Dates and times: Separate dates, local times, offsets, durations and other temporal forms.
  • Space-separated tokens: Token-list syntax does not define the meaning of every individual token.
  • URLs: Resolution, base URLs and URL-related authoring requirements.
  • Link types: Relationships and their allowed link/anchor contexts.
  • Metadata names: Defined names and the relevant extension mechanisms.
  • Autocomplete purposes: Tokens describe field purpose and have ordering and applicability rules.
  • Input type states: 22 states in the captured snapshot; state-specific constraints remain important.
  • Form submission: Entry lists, methods, encodings, targets and overrides.
  • Iframe sandbox: Permission tokens restore capabilities to a restricted browsing context.
  • Script processing: Classic/module behavior, recognized type values and processing rules.
  • HTML-defined HTTP headers and MIME discovery: Discovery lists are narrower than the entire HTTP and IANA registries.
