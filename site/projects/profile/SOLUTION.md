# Reference reasoning: Build a personal profile

The fragment teaches the profile content, not a complete document shell. The downloadable index.html supplies that shell and keeps the contact destination on the same page. A section heading identifies the contact topic; a link is appropriate because activation navigates rather than submitting data. The list expresses a collection of activities. Fictional status is part of the interface, not hidden assessment metadata.

## Explained exercise answer

The contact-navigation checks fail because the button has neither a destination nor an implemented action. Content truth also fails: a reader can mistake the volunteer and contact route for real offerings. Restore an anchor whose href is #contact, retain a unique contact section that states no route is supplied, and restore the visible fictional notice. Test Enter activation and the narrow page again. Styling alone cannot repair the broken task.
