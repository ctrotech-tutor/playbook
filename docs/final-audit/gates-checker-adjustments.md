# Full-gates pass: retained checker observations

- Whole-site axe checking found real target-size failures on reference/attributes.html, reference/elements.html and reference/globals.html. The original 330–422-page result is retained as entire-site-a11y-before-target-fix.json.gz. Link targets were given a bounded minimum block size, padding and wrapping gaps. The full 422-page audit was then repeated, with no rules disabled.
- The first discovery comparison used a non-HTML5 parser on WHATWG markup with optional end tags. Its nested cell search consequently mixed attribute names into the element count. Switching to html5lib yielded the actual 113 HTML names plus the separately classified SVG/MathML roots. No fabricated 237-element inventory was published.
- A first PDF text assertion included running headers and markers in page-stream drawing order. Copy comparison now uses sorted body-area extraction, excluding known running-margin artifacts; all 74 canonical code strings match after layout whitespace removal. Margin marked content was separately converted to PDF artifacts; it is not hidden source content.
- The first static-security harness incorrectly required a book-shell CSP meta element on the passive transcript resource. The resource has no script, iframe, form, object or embed, and the global host response policy covers its path. The harness now explicitly verifies those facts instead of treating missing page-specific meta as a demonstrated vulnerability. The book-shell meta checks and all active-content/resource/handler checks remain enabled.
